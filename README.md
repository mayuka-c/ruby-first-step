# Ruby First Step

A comprehensive learning guide for Ruby programming fundamentals and advanced concepts. This repository contains hands-on examples and exercises organized progressively from basics to professional-level Ruby features.

## 📚 Content Structure

| Folder | Topics |
|--------|--------|
| **01_Basics** | Hello World, variables, operators, input/output |
| **02_Control_Statements** | Conditionals, loops, flow control |
| **03_Methods_and_Blocks** | Method definitions, blocks, yield |
| **04_Strings** | String manipulation, interpolation, advanced methods |
| **05_Debug** | Debugging techniques, step execution, info inspection |
| **06_Arrays** | Array operations, iterations, cloning |
| **07_Ranges** | Range creation, iteration, random selection |
| **08_Hashes** | Hash creation, access, iteration |
| **09_Blocks_Procs_Lambdas** | Closures, procs, lambdas, and their differences |
| **10_OOP** | Classes, inheritance, keyword arguments |
| **11_Modules** | Module definition, namespacing |
| **12_Mixins** | Include, extend, composition patterns |
| **13_Exceptions** | Error handling, custom exceptions, rescue/retry |
| **14_Testing** | Unit testing with Ruby test framework |
| **15_Gems** | Package management with Bundler, using external gems |

## 🚀 Getting Started

```bash
# Clone the repository
git clone https://github.com/mayuka-c/ruby-first-step.git
cd ruby-first-step

# Run any Ruby file
ruby 01_Basics/hello.rb
```

## 📋 Prerequisites

- Ruby 3.2+ installed on your system

---

**Ideal for**: Learning Ruby from scratch, reviewing fundamentals, or preparing for Ruby development.
